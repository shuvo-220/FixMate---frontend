# FixMate – Frontend

FixMate is a smart device and home appliance repair service platform that connects customers with professional technicians. Users can explore repair services, book technicians, track booking status, and make secure online payments through Stripe.

Technicians can create and manage repair service listings, handle customer bookings, and update job statuses. Admins can manage users, approve services, monitor bookings, and track transactions.

## Technologies Used

- Next.js
- React.js
- Tailwind CSS
- DaisyUI
- Better Auth
- Axios
- React Icons
- Sonner
- Stripe Checkout

## Key Features

- Responsive and modern user interface
- User authentication and role-based dashboards
- Service browsing and booking
- Technician service management
- Admin management system
- Secure Stripe payment integration
- Profile management and image upload
